## Hashmi token rotation

A temporary contest build may contain the former Hashmi gateway token. Removing the source file cannot revoke an installed build. Rotate the gate token on the **home PC** and update Khazna's `LOCAL_LLM_TOKEN` secret together, then redeploy Khazna's `askTutor` and confirm it works. Use Khazna's own operations guide and keep its existing gateway URL. This Mac has no copy of the PC's `.env` and no remote PC access, so this step was not performed. Deleting old demo installs is also recommended. Until rotation, an old build with the embedded token may still directly reach the gate.
